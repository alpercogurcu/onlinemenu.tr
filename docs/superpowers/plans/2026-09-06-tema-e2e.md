# Admin Tema, Ekran Tutarlılığı ve Rol Bazlı E2E — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin panelinde temayı tek kaynaktan yönetmek (KDS dahil hiçbir ekran `.dark` zorlamaz), koyu temanın kalitesini yükseltmek, ekranlar arası tutarsızlıkları (breadcrumb, sidebar, Kullanıcılar sayfası, 404/500 veren sayfalar) gidermek ve rol bazlı Playwright e2e paketi kurmak (yönetici, shift müdürü, kasiyer, garson, mutfak).

**Architecture:** Yalnız admin frontend + üç küçük backend dokunuşu (üyelik listesine ad/e-posta, dev seed'e rol kullanıcıları, tenant yanıtına `enabled_modules`). Playwright e2e `web/apps/admin/e2e/` altında, dev yığınına karşı (`/dev/login` e-posta kısayolu ile rol değiştirerek). Tema: next-themes + CSS token'ları; durum renkleri token'a bağlanır.

**Tech Stack:** Next.js 16, Tailwind v4 (`@theme inline`), next-themes, shadcn; @playwright/test; Go chi/pgx.

**Spec:** Claude Design canvas'ı https://claude.ai/code/artifact/f74fd0ae-67b2-4268-9c4f-f9a3455fcdc5 (tema token'ları, KDS açık/koyu, Kullanıcılar) + denetim notları `.superpowers/ux-audit/findings.md` (git-ignored; özeti aşağıda).

## Global Constraints

- Tema tercihi kullanıcıya ait (`next-themes`, `html.dark`). Hiçbir sayfa/bileşen kökünde `dark` sınıfı veya ham `neutral-900`/`zinc-*`/`text-white` renk sınıfı kullanmaz; her şey `bg-background`, `bg-card`, `text-muted-foreground`, `border-border` ve yeni durum token'larıyla yazılır.
- Durum token'ları (`globals.css` `:root` ve `.dark`): `--status-success-{bg,fg,border}`, `--status-warning-*`, `--status-info-*`, `--status-danger-*`, `--status-neutral-*`; Tailwind v4 `@theme inline` ile `bg-status-success` vb. utility'ler. Değerler canvas artboard 1'deki gibi (açık: `#ecfdf3/#067647/#abefc6`, `#fff4e5/#b45309/#fcd9a6`, `#eef4ff/#1d4ed8/#c7d7fe`, `#fef2f2/#b91c1c/#fecaca`, `#f5f5f5/#525252/#e5e5e5`; koyu: `rgba(34,197,94,.14)/#86efac/rgba(34,197,94,.35)`, `rgba(245,158,11,.14)/#fcd34d/rgba(245,158,11,.35)`, `rgba(59,130,246,.14)/#93c5fd/rgba(59,130,246,.35)`, `rgba(239,68,68,.14)/#fca5a5/rgba(239,68,68,.35)`, `rgba(255,255,255,.08)/#d4d4d4/rgba(255,255,255,.14)`).
- Koyu tema token düzeltmeleri: `--background oklch(0.16 0 0)`, `--card oklch(0.22 0 0)`, `--popover oklch(0.22 0 0)`, `--border oklch(1 0 0 / 14%)`, `--sidebar-primary = --primary`, `--chart-1 oklch(0.70 0.18 25)`, `--chart-2..5` nötr/marka tonları (mavi/mor yok).
- Türkçe UI yalnız next-intl; kod/yorum İngilizce; commit Türkçe, AI attribution yok; push yok. Dal: `feat/admin-tema-e2e` (katalog dalı `main`'e alındıktan sonra ondan açılır).
- Testler: vitest (bileşen) + Playwright e2e (`task web:e2e`). E2E dev yığını ister (`task compose:up:core`, migrate, seed, API :8081, admin :3000); CI'da ayrı iş, `if: env.E2E == 'true'` ile opsiyonel.
- Paralel görevler ayrık dosya kümeleriyle çalışır; `git add` yalnız kendi yolları.

### Rulings

- **R1** API'de mount edilmemiş modüllerin (party, hr-core, billing) sayfaları pilotta gösterilmez: sidebar bölümleri `tenant.enabled_modules ∩ MOUNTED_MODULES` ile süzülür; `MOUNTED_MODULES` admin'de sabit (`["pos","catalog","inventory","storefront"]`), dev seed'in `enabled_modules`'ı da buna çekilir. Modüller mount edildiğinde sabit güncellenir.
- **R2** Sondaki eğik çizgi: frontend hook'ları backend'in `Get("/")` rotalarına uyar; 404'ün asıl sebebi modüllerin mount edilmemesi. Hook URL'leri değişmez; R1 sayfaları gizler.
- **R3** KDS için cihaz bazlı "Koyu mod" anahtarı: sayfa kökünde `data-theme="dark"` + `.dark` sınıfını **yalnız anahtar açıkken** uygular (localStorage `kds-dark`), varsayılan uygulama teması.
- **R4** E2E'de rol değiştirme `/dev/login` ile (Keycloak yok); seed'e her rol için bir kişi eklenir (dev-only SQL).
- **R5** Kullanıcılar sayfası ad/e-posta gösterir: backend `GET /v1/identity/{tenant}/memberships` yanıtı `person_name`, `person_email` alanlarıyla zenginleştirilir (persons JOIN, aynı RLS tx'i).
